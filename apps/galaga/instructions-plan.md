# plan 서브에이전트 지침: 갤러그 게임

## 역할
갤러그 웹앱의 **계획서만** 작성한다. 코드는 구현하지 않는다.

## 수정 허용 범위
- 생성/수정 가능: `/Users/cky/dev/my-blog/apps/galaga/spec.md` (이 파일 하나뿐)
- 그 외 모든 파일은 읽기만 한다. 특히 블로그 파일(`index.html`, `post.html`, `css/`, `js/`, `posts/`, `CLAUDE.md`, `.claude/`)은 수정 금지.
- 참고용으로 `/apps/2048/` (구조, 테마 처리, 입력 처리 방식)을 읽어도 된다.

## 프로젝트 규칙 (CLAUDE.md 발췌)
- html, js, css만 사용한다. 프레임워크 금지.
- 웹앱은 `/apps/galaga/` 폴더 안에서 자체 완결된다.
- 외부 라이브러리는 최소화한다. 가능하면 사용하지 않는다. CDN은 허용.
- 모바일에서도 사용할 수 있어야 한다.

## 사용자 요구사항
- 갤러그 스타일 슈팅 게임 (아래로 내려오는 적 편대를 하단의 자기 기체로 격추)
- **기본 목숨은 5개**
- 점수판 포함 (현재 점수, 최고 점수, 남은 목숨, 스테이지)

## spec.md에 반드시 포함할 내용
1. **개요**: 만들 앱 한 문단 요약
2. **기능 목록**: 필수 기능과 선택 기능을 구분
   - 필수: 좌우 이동 + 발사(연사 제한), 적 편대 등장·이동·공격 급강하, 적 탄환, 충돌 판정, 목숨 5개(상수 하나로 정의), 피격 시 무적 시간, 스테이지 진행(전멸 시 다음 단계, 난이도 상승), 게임 오버, 시작/일시정지/재시작
   - 모바일: 터치 조작(좌우 이동 + 발사), 작은 화면 대응
   - 최고 점수 저장 (localStorage, 접근 실패 시 동작)
3. **게임 규칙 정의**: 목숨 수(5), 점수표(적 종류별), 피격·무적 시간, 스테이지별 난이도 변화, 추가 목숨 부여 여부, 적 급강하 규칙
4. **파일 구조**: `/apps/galaga/` 안의 파일 목록과 책임 (예: `index.html`, `style.css`, `game.js` 순수 로직, `ui.js` 캔버스 렌더·입력·루프)
5. **렌더링 설계**: canvas 사용 여부, 논리 해상도와 화면 스케일링, devicePixelRatio, 고정 시간 간격 루프(requestAnimationFrame), 스프라이트는 코드로 그리기(이미지 파일 최소화), 라이트/다크 모드 대응
6. **입력 처리**: 키보드(←→/AD, 스페이스), 터치 조작 방식, 페이지 스크롤 충돌 방지(`touch-action`, 방향키·스페이스 preventDefault)
7. **접근성**: 키보드 조작, 점수·목숨 aria-live 안내, 움직임 줄이기 설정 고려
8. **엣지 케이스**: 탭 비활성화 시 자동 일시정지, 창 크기 변경, 프레임 드랍 시 delta 상한, iframe 미리보기(블로그 카드)에서의 자동 재생 방지, 동시 충돌
9. **검증 체크리스트**: review 단계에서 확인할 항목 목록 (목숨 5개 확인 포함)
10. **열린 질문**: 사용자에게 확인이 필요한 결정 사항 (없으면 "없음")

## 작성 방식
- 한국어로, 구현자가 그대로 따를 수 있을 만큼 구체적으로 쓴다.
- 수치(속도, 연사 간격, 무적 시간, 편대 크기 등)는 초기값을 제시한다.
- 과한 기능은 넣지 않는다. 요구사항 범위를 지킨다.
