# 2048 검증 리포트 (review)

## 1. 요약

**조건부 통과.** 로직(Node)과 브라우저 동작 검증은 모두 통과했고, 기능상 실패는 없다. 다만 사소한 규칙 위반 1건(`index.html` 인라인 테마 스크립트의 `var`)과 UI 가독성 개선점 1건(오버레이 불투명도)을 발견했다. 검증자의 수정 시도는 권한 분류기에 거부되었고, 메인 세션이 두 건 모두 직접 수정했다(3절 참조).

검증 환경 주의: 지침의 `mcp__Claude_Browser__*` 도구는 이 세션에서 사용할 수 없었다(ToolSearch 결과 없음). 대신 로컬에 설치된 Google Chrome을 헤드리스로 실행하고 Chrome DevTools Protocol(스크래치패드의 임시 Node 스크립트)로 실제 페이지(`http://localhost:8000/apps/2048/`)를 조작했다. 즉 브라우저 도구는 아니지만 실제 Chrome에서 실행해 확인했다. 스크린만 직접 눈으로 본 것은 일부(375px 다크, 게임 오버 라이트)뿐이다.

## 3. 발견한 문제와 수정 내역

검증자는 아래 두 건을 `sed -i`로 수정하려 했으나 권한 분류기("Irreversible Local Destruction")가 거부했고, 우회하지 않고 보고만 했다. 이후 **메인 세션이 Edit 도구로 제안대로 수정했다**(2026-10-06). 수정 후 확인은 `grep`으로 변경 내용만 확인했으며, 브라우저에서 오버레이를 다시 눈으로 확인하지는 않았다(미검증).

1. `index.html` 12줄 – 인라인 테마 스크립트의 `var t = ...` (CLAUDE.md/spec 9절 "`var` 미사용" 위반, 동작 영향 없음)
   - 제안 수정: `const t = localStorage.getItem('theme');`
2. `style.css` 10줄, 53줄, 91줄 – `--overlay-bg`의 알파가 0.86이라 게임 오버/2048 오버레이 뒤의 타일 숫자가 비쳐 제목 글자와 겹쳐 읽힘(라이트 모드 게임 오버 스크린샷에서 흰색 "128", "64"가 제목 위로 보임). 기능 오류는 아니고 가독성 문제.
   - 제안 수정: 세 곳 모두 알파 0.86 -> 0.95

기능 결함(로직 오류, 크래시, 콘솔 에러)은 발견하지 못했다.

## 4. 미검증 항목과 이유

- `mcp__Claude_Browser__*` 브라우저 도구: 사용 불가. 대체로 헤드리스 Chrome + CDP로 검증함(위 1절).
- 실기기 터치(iOS Safari, Android Chrome)의 스와이프, 당겨서 새로고침 방지: 미검증(CDP 터치 에뮬레이션만 수행).
- Firefox/Safari 동작: 미검증(Chrome만).
- 4자리 타일(1024/2048)이 375px 폭에서 실제로 넘치지 않는지 스크린샷 확인: 미검증(CSS 계산상으로만 판단).
- 2048 시나리오는 `game.js` 응답을 가로채 시작판을 바꿔서 확인했다. 정상 플레이로 2048에 도달한 것은 아니다. 또한 "계속하기" 후 2048 타일이 다시 생기는 경우의 재알림 없음은 Node(keepPlaying 상태 병합)와 코드(`syncOverlay`가 `keepPlaying`을 보므로)로 확인했고 브라우저로는 재현하지 않았다.
- FOUC 프레임 단위 측정, 화면 낭독기 실제 낭독: 미검증.

## 5. 남은 위험 또는 권고

- 3절 두 건의 수정 적용을 권장한다(둘 다 한 줄 수준).
- 2048 오버레이가 뜬 뒤 렌더(requestAnimationFrame) 전 같은 프레임 안에서 들어온 추가 입력은 처리된다(`overlayMode`는 렌더 시점에 갱신). 한 프레임 이내라 실사용 영향은 거의 없으나 엄밀히는 spec 6절 "오버레이 표시 중 이동 무시"에서 1프레임 틈이 있다.
- 한글 IME가 켜진 상태에서는 WASD가 `ㅈㅁㄴㅇ`로 입력되어 동작하지 않는다(`event.key` 기준). 방향키는 영향 없음.
- 모듈 전역 `nextId`는 새로고침 시 초기화되나 DOM이 함께 초기화되므로 문제 없다.
- 새 게임 시 시작 타일에 생성 애니메이션이 없는 것은 코드 주석대로 의도된 동작이다.
