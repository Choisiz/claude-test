클로저(Closure)는 **함수와, 그 함수가 선언된 렉시컬 환경의 조합**입니다. 쉽게 말해, 함수가 자신이 만들어진 곳의 변수를 *기억*하고 나중에 호출될 때도 접근할 수 있는 성질입니다.

## 가장 단순한 예

```js
function makeCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

`makeCounter`의 실행은 끝났지만, 반환된 함수는 여전히 `count`에 접근합니다. 바깥 함수가 종료되어도 안쪽 함수가 참조하는 변수는 사라지지 않기 때문입니다.

## 어떻게 동작할까

1. 함수는 **선언된 위치**를 기준으로 상위 스코프를 결정한다. (렉시컬 스코핑)
2. 내부 함수가 상위 스코프의 변수를 참조하면, 그 변수는 가비지 컬렉션 대상에서 제외된다.
3. 함수를 호출할 때마다 **독립된 환경**이 만들어진다.

```js
const a = makeCounter();
const b = makeCounter();

a(); // 1
a(); // 2
b(); // 1  ← a와 상관없이 따로 센다
```

## 어디에 쓸까

### 1. 데이터 은닉

`count`는 바깥에서 직접 바꿀 수 없고, 반환된 함수를 통해서만 접근할 수 있습니다.

```js
function createAccount(initial) {
  let balance = initial;

  return {
    deposit(amount) {
      balance += amount;
      return balance;
    },
    getBalance() {
      return balance;
    },
  };
}

const account = createAccount(1000);
account.deposit(500);
console.log(account.getBalance()); // 1500
console.log(account.balance);      // undefined
```

### 2. 설정을 기억하는 함수 만들기

```js
const multiply = (x) => (y) => x * y;

const double = multiply(2);
const triple = multiply(3);

console.log(double(5)); // 10
console.log(triple(5)); // 15
```

### 3. 이벤트 핸들러와 콜백

핸들러가 만들어질 때의 값을 그대로 가져갈 수 있습니다.

```js
function setup(button, message) {
  button.addEventListener('click', () => {
    alert(message); // setup이 끝난 뒤에도 message를 기억한다
  });
}
```

## 자주 하는 실수: 반복문과 var

> `var`는 함수 스코프라서, 반복문 안에서 만든 함수들이 **같은 변수 하나**를 공유합니다.

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 3, 3, 3
```

`let`은 반복마다 새로운 바인딩을 만들기 때문에 기대한 대로 동작합니다.

```js
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 0, 1, 2
```

## 주의할 점

- 클로저가 큰 객체를 참조하고 있으면 **메모리가 해제되지 않습니다.** 더 이상 필요 없으면 참조를 끊어 주세요.
- 클로저를 과하게 중첩하면 흐름을 따라가기 어려워집니다.

## 정리

| 개념 | 설명 |
| :--- | :--- |
| 렉시컬 스코프 | 함수가 **선언된 위치**로 변수 범위가 정해진다 |
| 클로저 | 함수 + 선언 당시의 환경 |
| 대표 활용 | 데이터 은닉, 커링, 콜백, 모듈 패턴 |

클로저는 특별한 문법이 아니라, 자바스크립트에서 함수가 일급 객체이고 렉시컬 스코프를 따르기 때문에 **자연스럽게 생기는 결과**입니다.
